# Knowledge Base Creation

## Structure
```
kb/
  index.md          # Main index
  concepts/
    async.md        # Async programming
    threading.md    # Threading patterns
  guides/
    setup.md        # Setup guide
  references/
    cheatsheet.md   # Quick reference
```

## Linking
```markdown
See [[async.md]] for more on async patterns.
Related: [[threading.md]]
```

## Usage
- Keep pages focused on one topic
- Link related concepts
- Use consistent formatting
