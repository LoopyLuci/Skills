# Social Media Ad Copywriting

## Overview

A complete system for writing high-converting social media ad copy across platforms. Covers headline formulas (PAS, FAB, AIDA frameworks), platform-specific copy structures, CTAs, audience targeting hints embedded in copy, A/B test plans by funnel stage, and creative-to-copy alignment. Designed for paid social managers, growth marketers, and copywriters running ads on Meta, TikTok, LinkedIn, X/Twitter, and YouTube.

## When to Use

- **Writing ad copy** for a new campaign or creative refresh
- **Structuring A/B tests** for ad creative optimization
- **Tailoring copy per funnel stage** (TOF → MOF → BOF)
- **Optimizing underperforming ads** — diagnosing and rewriting weak copy
- **Launching a product** with coordinated paid social campaigns
- **Scaling winning ads** — extracting patterns from high-CTR/high-CVR copy

## Body

### Part 1: Copywriting Frameworks

#### 1.1 AIDA (Attention → Interest → Desire → Action)

| Stage | What | Example |
|---|---|---|
| **Attention** | Bold statement or question | "Stop wasting $5K/month on ads that don't convert." |
| **Interest** | Expand on problem or opportunity | "Most optimize for CTR, not CVR. That's costing you." |
| **Desire** | Show transformation | "Clients see 3× ROAS in 30 days with our framework." |
| **Action** | Direct CTA | "Book a free audit → [CTA Button]" |

**Best for:** MOF (mid-funnel), consideration-stage campaigns.

#### 1.2 PAS (Problem → Agitate → Solve)

| Stage | What | Example |
|---|---|---|
| **Problem** | Name the pain | "Your impressions are high but conversions are low." |
| **Agitate** | Consequence of inaction | "You're bleeding budget to low-intent clicks. $XXX wasted." |
| **Solve** | Your solution | "Our algorithm targets buyers, not browsers." |

**Best for:** Pain-point-driven, B2B, high-consideration products.

#### 1.3 FAB (Features → Advantages → Benefits)

| Stage | What |
|---|---|
| **Features** | "Real-time A/B testing across 6 variations." |
| **Advantages** | "Find winning copy 3× faster." |
| **Benefits** | "Stop wasting budget on losing ads. Scale winners immediately." |

**Best for:** Product-led campaigns, SaaS.

#### 1.4 4U's (Urgent → Unique → Useful → Ultra-Specific)

| Element | Example |
|---|---|
| Urgent | "This pricing ends Friday." |
| Unique | "The only scheduler with built-in AI copy optimization." |
| Useful | "Save 10 hours/week on ad management." |
| Ultra-specific | "3,247 marketers use this." |

**Best for:** TOF awareness, limited-time offers.

### Part 2: Platform-Specific Ad Copy

#### 2.1 Meta (Facebook + Instagram)

**Structure:**
- **Primary Text** (125–150 chars): Hook → 2–3 lines body → CTA bridge
- **Headline** (40 chars max): Benefit-forward, keyword-rich
- **Description** (30 chars): Supporting detail or price
- **CTA Button**: Shop Now / Learn More / Sign Up / Get Offer / Download / Book Now

**TOF (Awareness):**
```
PRIMARY: "Tired of [pain]? [Stat] of [audience] struggle with this.
Here's how we solve it: [1-line solution]. See how →"
HEADLINE: "Stop [Pain] Today"
```

**MOF (Consideration):**
```
PRIMARY: "Most [audience] think [belief]. The truth? [contrarian truth].
Here's proof: [testimonial or case study]. Ready to try?"
HEADLINE: "[Result] in [Time]"
```

**BOF (Conversion):**
```
PRIMARY: "Last chance to [benefit]. Ends [date].
[Number] already [result]. No risk: [guarantee]. Claim yours →"
HEADLINE: "Offer Ends [Date]"
```

**Creative-to-Copy Alignment:**
- People in creative → Copy: problem → solution → transformation
- Product in creative → Copy: features → advantages → proof → CTA

#### 2.2 TikTok Ads

**Structure:**
- **Caption** (100–150 chars): Hook → 1 line value → 3–5 niche hashtags
- **On-screen text** (most important — 40% watch without sound): Hook at 0s, reinforce at 10s, CTA at end

**Hook types:** "POV: You just discovered [solution]." / "I found the cheat code for [problem]." / "Stop doing [mistake]. Do this instead."

```
CAPTION: "POV: You found the [product] that delivers on [promise]. Try it 👇"
ON-SCREEN: [0s: "STOP SCROLLING ⛔"] [10s: "HERE'S THE HACK ↓"] [25s: "TRY IT NOW"]
```

**Rules:** Creator voice > brand voice. Trend audio > original for TOF. Native-looking > polished 3:1.

#### 2.3 LinkedIn Ads

**Structure:**
- **Headline** (150 chars): Role-specific problem + result + social proof
- **Text** (600 chars recommended): Hook → 2–3 paragraphs + bullets + social proof + CTA

```
HEADLINE: "[X]% of [Industry] Leaders Use [Solution]. Here's Why."
TEXT: "Most [role]s struggle with [pain]. Cost: [stat].
We helped [customer] achieve [result] in [timeframe].
• [Benefit 1 with data]
• [Benefit 2 with data]
Download the case study → [CTA]"
```

**Rules:** Professional, authoritative, data-heavy (outperforms emotional 2:1). For InMail: personal, helpful, value-first.

#### 2.4 X/Twitter Ads

**Structure:**
- **Tweet** (280 chars): Hook → 1–2 lines → CTA + link
- **Media**: Required. 1200×675 (16:9). Text-only underperforms.

```
"Hot take: [contrarian statement]. The data: [stat].
If you're in [role], this changes [topic].
Read the thread → [link]"
```

**Rules:** Speed matters (reference current events). Controversy drives CTR on X. Shortest copy of any platform.

#### 2.5 YouTube Ads

**Skippable In-Stream Script:**
```
0:00–0:05: "Want to [outcome]? Keep watching."
0:05–0:15: "The old way: [inefficient]. What works: [approach]."
0:15–0:45: "How it works: Step 1 [X] → Step 2 [Y] → Step 3 [Z]"
0:45–1:00: "Proof: [testimonial/number/case study]"
1:00–1:15: "CTA with urgency"
```

**Discovery Ad:** Headline (30 chars, benefit-forward, SEO). Description (2 lines).

**Rules:** Hook in first 5 seconds. Non-skippable (6s bumpers): one message (brand + benefit + CTA). Discovery ads need keyword research.

### Part 3: CTA Formulas

| Stage | CTA Style | Examples |
|---|---|---|
| TOF | Curiosity / Low-friction | "See how" / "Watch the video" |
| MOF | Value exchange | "Get the free guide" / "Download the report" |
| BOF | Direct + urgency | "Shop now — 20% off ends today" / "Book your demo" |
| Retention | Community + loyalty | "Join 10K+ members" / "Refer a friend" |

**High-performers:** "See what's inside", "Last chance", "Join 10,000+ [audience]", "Try free for 30 days", "Start saving [X]/month", "Become a [identity]".

### Part 4: Audience Targeting Hints in Copy

Embedding audience signals in copy improves relevance scoring:

| Platform | What to Include | Why |
|---|---|---|
| Meta | "For [role] in [industry]" | 10%+ CTR lift on relevance score |
| LinkedIn | Job titles, industries, companies | Algorithm checks copy-to-audience alignment |
| TikTok | Vibe/trend matching, not explicit targeting | Algorithm uses interest graph, not keywords |
| X | Hashtags + keywords matching topic targeting | Heavy keyword targeting |
| YouTube | Match headline to search keywords + interest | Discovery ads = keyword-matched |

**Example (Meta):** Target: "Small business owners, 25–55, interested in social media marketing". Copy: "Attention small business owners. Stop guessing your social media strategy."

### Part 5: A/B Test Plans by Funnel Stage

**TOF — Variable: Hook**
```
Control: Curiosity hook
Variant A: Question hook
Variant B: Stat hook
Variant C: Contrarian hook
Metrics: CTR, CPM. Sample: 5K impressions/variant. Duration: 3–7 days.
```

**MOF — Variable: Social Proof**
```
Control: Testimonial
Variant A: Number proof ("[X] customers trust us")
Variant B: Data proof ("[Stat] improvement")
Variant C: Authority proof ("Featured in [publication]")
Metrics: CTR, CVR, CPL. Sample: 1K clicks/variant. Duration: 5–10 days.
```

**BOF — Variable: Urgency**
```
Control: Scarcity ("Only X left")
Variant A: Time limit ("Ends [date]")
Variant B: Exclusivity ("First X get bonus")
Variant C: Risk reversal ("Free returns / 30-day guarantee")
Metrics: CVR, AOV, ROAS. Sample: 500 clicks/variant. Duration: 5–10 days.
```

### Part 6: Creative Brief Template

```markdown
## Ad Creative Brief: [Campaign]
- **Platform**: [Meta / TikTok / LinkedIn / X / YouTube]
- **Funnel Stage**: TOF / MOF / BOF
- **Audience**: [Demographic + targeting]
- **Goal**: [Clicks / Conversions / Leads]
- **Hook**: [Primary line]
- **Body (2–3 sentences)**: [Value prop, pain, social proof]
- **CTA**: [Button text]
- **Tone**: [Authoritative / Friendly / Urgent / Conversational]
- **Format**: [Single image / Carousel / Video / Stories]
- **Test variable**: [Hook / Social proof / CTA / Visual]
- **Control**: [Current best]
- **Variants**: [3–4 alternatives]
- **Success metric**: [CTR / CVR / ROAS]
```

### Part 7: Pre-Launch Quality Gate

```
☐ Hook visible in first 2 lines / first 5 seconds of video
☐ Single, clear value proposition
☐ Audience language matches targeting
☐ CTA is specific and action-oriented
☐ Social proof present (testimonial, number, stat, or logo)
☐ Ad-to-landing page message match (headline + CTA match page)
☐ Platform-specific formatting applied
☐ Urgency/scarcity for BOF campaigns
☐ Emoji use intentional (1–2 max, adds meaning)
☐ UTM parameters set: utm_source, utm_medium, utm_campaign, utm_content
☐ FTC disclosure if applicable (testimonial or affiliate)
☐ Spelling + grammar checked
☐ Read aloud — sounds human?
```

## Common Pitfalls

- **Multiple messages**: One ad = one message. Confusing the algorithm and user kills CTR.
- **No social proof**: Unsourced claims underperform 3:1. Every ad needs some proof.
- **Generic CTAs**: "Learn More" is lazy. Be specific: "Get the Free Checklist".
- **Ad-to-landing page mismatch**: Ad says "50% off", page shows full price = tanked CVR.
- **Not testing**: Running one ad = gambling. Always run ≥3 variants.
- **Copy-creative mismatch**: Headline on image must match ad copy's hook.
- **Overwriting**: LinkedIn can handle 600 words. TikTok can't handle 200.
- **No UTMs**: Without them, you're flying blind on attribution.
- **Emoji abuse**: 5 emojis on LinkedIn = credibility destroyed. 1–2 on Meta is fine.
- **Wrong funnel copy**: "Buy Now" to a cold audience never works. Match to funnel stage.
- **Features vs benefits**: "10GB storage" = feature. "Store 10,000 photos" = benefit.
