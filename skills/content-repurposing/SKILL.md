# Content Repurposing

## Overview

Systematically transform a single blog post into 8+ content formats tailored to different platforms. Maintains the core message while adapting tone, length, format, and delivery for each audience. Maximizes ROI on every piece of content you create.

## When to Use

- You've published a high-performing blog post and want to maximize its reach
- You have limited content creation time and need more output from each asset
- You manage multiple channels (blog, email, social, video, podcast) and need cross-platform content
- You want to reach audiences on platforms they actually use (LinkedIn, Reddit, YouTube, etc.)

## Core Principle

One core message → Multiple formats → Targeted distribution.

## Repurposing Playbooks

### 1. Blog → LinkedIn Post

**Goal:** Professional/industry-specific version optimized for LinkedIn's feed algorithm.

**Format:**
```
[Grabby hook — stat, bold claim, or contrarian take]
[2–3 paragraph body — key insight from the post]
[1–2 bullet points with the most actionable takeaways]
[Discussion question or opinion invitation]
[Soft CTA: link to full post in comments or first comment]
```

**Rules:**
- Keep it 1,200–1,500 characters (LinkedIn truncates longer posts with "see more")
- Lead with a line break after the first sentence (LinkedIn algorithm rewards it)
- Tag relevant people/companies (but keep it to 3–5 max to avoid spam filtering)
- No external links in the main body text — put them in the first comment
- Use line breaks between paragraphs for readability
- Post between 8–10 AM or 12–1 PM (user's timezone) for best engagement
- Engage with comments within the first hour to boost algorithmic reach

**Templates:**
```
# Contrarian Take
Most people think [common belief]. But [data/fact] tells a different story.
In my latest post, I broke down [key insight].
The takeaway? [One-sentence actionable insight].
What's your take on this? Drop it in the comments 👇

# Listicle Digest
I spent [timeframe] researching [topic]. Here are the [N] most important findings:
→ [Finding 1]
→ [Finding 2]
→ [Finding 3]
→ [Finding 4]
→ [Finding 5]
Which of these surprised you most? 👇
```

### 2. Blog → Twitter/X Thread

**Goal:** Quick-scan serialized content optimized for X's scroll-and-engage behavior.

**Format (15–25 tweets):**
```
Tweet 1: Hook — surprising stat, question, or bold claim + [🧵]
Tweet 2: Context — the problem this addresses
Tweet 3-5: Background / setup
Tweet 6-18: Main points — one actionable insight per tweet
Tweet 19-23: Examples or case study highlights
Tweet 24: Summary / key takeaway
Tweet 25: CTA — "RT the first tweet if useful. Full post: [link]"
```

**Rules:**
- Each tweet must make sense on its own (people scroll through fragments)
- Max 2–3 lines per tweet (280 chars but shorter tweets perform better)
- One insight per tweet — never split a single idea across two tweets
- Use → , ↑ , or emoji arrows for visual flow
- Pin the 60-minute window after posting for engagement (reply to every meaningful reply)
- Add 2–4 images or quote-tweetable stat cards
- Quote the first tweet with a follow-up to keep the thread going
- No more than 1 link to the full post (usually tweet 3 or tweet 24)

**Thread Hook Formulas:**
```
[N] [noun] that will change how you [verb] [🧵]
I spent [time period] doing [hard thing]. Here's what I learned. [🧵]
Most [people/companies] get [topic] wrong. Here's the right way. [🧵]
Everything you know about [topic] is [wrong/outdated]. Let me explain. [🧵]
```

### 3. Blog → Email Newsletter

**Goal:** Personal, direct-to-inbox digest for existing subscribers.

**Format:**
```
Subject Line: [Curiosity-gap / benefit-driven / personalized]
Preview Text: [Compelling second hook, ~60-80 chars]

--- Body ---
Hey [First Name],

[1-2 sentence opener — personal connection to the topic]

[3-5 sentence summary of the post — the "what" and "why it matters"]

[1-2 key takeaways with bullet points or quick stats]

[Personal insight or opinion — not just summary, add value]

[PS with a personal note, question, or secondary resource]

[CTA: "Read the full post →"]
```

**Rules:**
- Subject line under 50 characters
- Preview text never matches the subject line — complementary second hook
- One topic per email
- Use plain text or minimal formatting (template-like emails get filtered)
- Keep it 200–400 words (including the bullet list)
- Always include a question to drive replies (engagement = better deliverability)
- Link to the full post (not the whole post pasted inline)
- Add a PS with something extra (tool recommendation, quote, or behind-the-scenes note)

### 4. Blog → Video Script (YouTube / Shorts / TikTok)

**Goal:** Visual narrative adapted for video-first platforms.

**YouTube (8–15 min):**
```
Hook (0:00-0:30): Same hook as blog post, but spoken — start with a question or visual
Intro (0:30-1:30): What the video covers and why they should watch
Body (1:30-12:00): Walk through the blog post's key sections visually
  - Show screenshots, slides, demonstrations
  - Speak the main points (not read word-for-word)
  - Add examples, personal stories, or extra depth
CTA Mid-roll (5:00): "Like and subscribe" / "Check the description for the full guide"
Conclusion (12:00-14:00): Summary, key takeaway, ask to comment
End Screen (14:00-15:00): Link to full blog post, related video, subscribe
```

**Shorts / TikTok / Reels (30–90 seconds):**
```
0:00-0:05 — Hook (text overlay: "Stop doing X, do Y instead")
0:05-0:30 — The problem (fast cuts, high energy)
0:30-0:55 — The solution (visual demonstration, on-screen points)
0:55-1:25 — The result / proof
1:25-1:30 — CTA ("Follow for more / Link in bio / Full blog post")
```

**Rules:**
- Write for the ear, not the eye — use shorter sentences, contractions, pauses
- No paragraph longer than 2 spoken sentences
- Add timestamps to key sections for YouTube chapters
- Include captions/subtitles for silent viewing
- Thumbnail design with text overlay previewing the hook
- Description includes a link to the full blog post + timestamps

### 5. Blog → Podcast Outline

**Goal:** Conversational long-form audio for an interview or solo episode.

**Format:**
```
Episode Title: [Same topic, framed for audio]

[0:00-2:00] Intro — Who you are, what you're covering today
[2:00-5:00] The Problem — what prompted the blog post topic
[5:00-15:00] Key Insight #1 — expand on the first major section
[15:00-25:00] Key Insight #2 — dive deeper, add what wouldn't fit in the post
[25:00-35:00] Key Insight #3 — examples, stories, listener scenarios
[35:00-40:00] Contrarian take or "what most people get wrong"
[40:00-45:00] Actionable steps / toolkit
[45:00-48:00] Summary + CTA (rate/review, subscribe, link to full post)
[48:00-50:00] Outro / next episode teaser
```

**Rules:**
- Replace written examples with spoken stories
- Add "what I didn't include in the post" as exclusive audio content
- Mention the blog post as "show notes" for detailed links
- Keep it to 20–50 minutes for solo, 30–60 minutes for interviews
- Add chapter markers in the audio file metadata
- Publish on Spotify, Apple, Google, and YouTube as podcast video

### 6. Blog → Infographic

**Goal:** Visual one-pager for Pinterest, LinkedIn carousel, SlideShare, embedded images.

**Design:**
```
Canvas: 800×2000 px or 1080×1920 px (vertical)
Top: Title in bold, minimal text
Sections: 4–6 visual blocks, each representing one H2
  - Each block: icon + headline + 1–3 bullet stats/facts
Bottom: Source URL + logo + "Full post at [link]"

Style: Brand colors, 2–3 complementary colors
      Sans-serif font, 2 font sizes max
      White space: 30% of canvas should be empty
```

**Tools:**
- Canva (free templates for infographics)
- Adobe Express
- Visme
- Piktochart
- Figma (custom design)

**Distribution:**
- Pinterest (vertical pin, keyword-rich description)
- LinkedIn carousel (PDF upload, 4–8 slides)
- Embed in the original blog post at the top as a visual summary
- SlideShare / Speaker Deck for long-form visual
- Medium post with the infographic as hero image + short commentary

### 7. Blog → Reddit Post

**Goal:** Platform-native content for niche subreddits.

**Format:**
```
Title: [Question or "I just learned X — here's what surprised me"]

[1–2 paragraph summary of the key finding/insight]
[Brief context about why you looked into this]
[One powerful data point or quote from the post]
[Question back to the community: "Has anyone else experienced this?"]

[Link in comments or sidebar — never in the post body]
```

**Rules:**
- Read the subreddit rules before posting (most ban self-promotion)
- Never link directly in the post body — put the URL in a comment or the post footer
- Focus on being helpful, not promotional. "Here's what I found" not "Read my post"
- Engage with every comment within the first 2 hours
- Use subreddit-specific formatting (e.g., r/SEO might appreciate data, r/Entrepreneur wants actionable stories)
- Never post the same content across multiple subreddits (shadowban risk)
- Add a "TL;DR" at the end of long posts

### 8. Blog → SlideShare / Presentation

**Goal:** Professional deck for SlideShare, SpeakerDeck, or embedded slides in the post.

**Format:**
```
Slide 1: Title slide (headline + author name + date)
Slide 2: The problem (stat or question)
Slide 3-5: Key insights (one per slide)
Slide 6-8: Data / evidence (charts, screenshots)
Slide 9-10: Actionable takeaways or checklist
Slide 11: Summary slide
Slide 12: CTA + link to full post + contact info
```

**Rules:**
- Max 15 slides (SlideShare users have short attention spans)
- One idea per slide
- 30–50 words max per slide
- Strong visuals: charts, graphs, screenshots, icons
- Export as PDF for SlideShare / SpeakerDeck
- Embed in the blog post as supplementary content
- Include speaker notes for those who present it

## Repurposing Decision Matrix

| Platform | Best For | Content From | Effort | Reach Potential |
|----------|----------|-------------|--------|-----------------|
| LinkedIn | Professional insights | Listicle, data, opinion | Medium | High (B2B) |
| Twitter/X | Quick insights, virality | Listicle, hot take | High | Very High |
| Email | Deep relationship | How-to, pillar, case study | Medium | Medium |
| YouTube | Tutorial, education | How-to, guide, comparison | High | Very High |
| Shorts/TikTok | Quick tips | One tip from any post | Medium | Very High |
| Podcast | Deep dive, authority | Pillar, opinion, interview | High | Medium |
| Infographic | Visual summary | Data, listicle, comparison | Medium | High |
| Reddit | Niche authority | Data, story, experience | Medium | Medium |
| SlideShare | Professional lead gen | Guide, data, framework | Medium | Medium |

## Common Pitfalls

- **One-size-fits-all:** Posting the same text to every platform ignores format expectations
- **Not adapting the tone:** LinkedIn is professional, Reddit is casual, Twitter is punchy — each needs a different voice
- **Too much self-promotion:** Reddit and LinkedIn punish heavy linking — focus on value, not traffic
- **Repurposing content that didn't perform:** If the blog post has zero traction, don't amplify a dud — pick posts with proven engagement
- **No platform-specific formatting:** A LinkedIn post without line breaks and a Twitter thread without media both underperform
- **Ignoring platform rules:** Each platform has content length, linking, and automation rules — violating them gets you shadowbanned
- **Repurposing the same post in the same week:** Space out repurposing over 2–4 weeks to avoid audience fatigue

## Verification Checklist

- [ ] Source blog post identified and confirmed top-performing (or strategically important)
- [ ] At least 3 repurposing formats selected from the matrix
- [ ] Each format adapted for its platform (tone, length, structure)
- [ ] Platform rules checked (no banned self-promotion)
- [ ] Links formatted per platform (in-post vs first-comment vs description)
- [ ] Visual assets created per format specs
- [ ] Repurposing scheduled across 2–4 weeks (not all at once)
- [ ] Tracking UTM parameters added to all links
- [ ] Engagement monitoring set for first 24 hours per platform
- [ ] Performance compared to original post (views, clicks, engagement rate)
