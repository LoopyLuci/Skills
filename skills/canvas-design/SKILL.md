# Canvas Design

Create beautiful visual art in .png and .pdf documents using a design philosophy. This skill follows a two-step process: (1) create a design philosophy and (2) express it visually on a canvas.

## Process

**User request** → **Design philosophy** → **Visual expression**

### Step 1: Design Philosophy Creation

Create a VISUAL PHILOSOPHY (4-6 paragraphs) interpreted through:
- Form, space, color, composition
- Images, graphics, shapes, patterns
- Minimal text as visual accent

Name the movement (1-2 words), then articulate covering:
- Space and form / Color and material
- Scale and rhythm / Composition and balance
- Visual hierarchy

### Example Philosophies
- **"Concrete Poetry"** — Massive color blocks, sculptural typography
- **"Chromatic Language"** — Color as the primary information system
- **"Analog Meditation"** — Quiet visual contemplation through texture
- **"Geometric Silence"** — Grid-based precision with negative space

### Step 2: Canvas Creation

Express the philosophy using:
- Repeating patterns and perfect shapes
- Sparse, clinical typography
- Limited, intentional color palette (3-5 colors)
- Systematic reference markers

### Text Guidelines
- Text is always minimal and visual-first
- Nothing falls off the page or overlaps
- Proper margins on all sides
- Design-forward font choices

## Craftsmanship Requirements

- Work should appear meticulously crafted
- No overlapping elements
- Museum/gallery quality output
- Sophisticated, never cartoony or amateur

## Output

Output as .pdf or .png file alongside the design philosophy as .md file.

## Common Pitfalls

- ❌ **Adding too much text** — Text should be sparse and essential
- ❌ **Overlapping elements** — Everything within canvas boundaries
- ❌ **Cartoony styles** — Always aim for gallery quality
- ❌ **AI-generated looking output** — Should feel hand-crafted

## Verification Checklist

- [ ] Design philosophy is 4-6 paragraphs
- [ ] Text is minimal, integrated as visual element
- [ ] Color palette has 3-5 intentional colors
- [ ] No elements overlap or fall off canvas
- [ ] Proper margins maintained throughout
- [ ] Output looks human-crafted, not AI-generated
