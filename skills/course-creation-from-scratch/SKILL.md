# Course Creation from Scratch

## Overview
Complete end-to-end course creation: ideation and validation, curriculum design, instructional design, content production, student engagement planning, platform setup, pricing, launch strategy, and student success optimization.

## When to Use
- "Create an online course from scratch"
- "I have expertise — how do I turn it into a course?"
- "Structure my course curriculum"
- "Launch a profitable online course"

## Phase 1: Ideation & Validation (Week 1)

### Step 1: Brainstorm Course Ideas
Use the **Expertise × Demand × Monetization** matrix:

| Idea | Your Expertise (1-5) | Market Demand (1-5) | Monetization Potential (1-5) | Total |
|------|---------------------|---------------------|------------------------------|-------|
| [Topic A] | | | | |
| [Topic B] | | | | |
| [Topic C] | | | | |

Pick the highest total that is also the most feasible to create.

### Step 2: Validate with Your Audience
1. **Existing audience check**: Do your email list, social followers, or clients ask about this topic?
2. **Pre-sell validation**: Create a landing page with a "Notify me when ready" form
   - If <20 signups in first week, abandon
   - If 20-100, proceed with caution
   - If 100+, strong signal
3. **Survey question**: "What's your biggest challenge with [topic]?"
4. **Competitor analysis**: Check Udemy, Coursera, Skillshare for competition
   - If top courses have 1,000+ reviews, demand exists
   - If courses are outdated, opportunity exists
   - If courses are perfect, look adjacent

### Step 3: Define Your Course Promise
Write in one sentence:
> "By the end of this course, students will be able to [specific outcome] without [common obstacle]."

This must be measurable and achievable in your course scope.

## Phase 2: Curriculum Design (Week 2)

### Backwards Design Method

#### Step 1: Define Your End Goal
What will students produce at the end?
- **Certificate exam**: Knowledge check
- **Portfolio project**: Real deliverable
- **Live demonstration**: Applied skill
- **Business result**: Measurable outcome (traffic, revenue, etc.)

#### Step 2: Design Your Final Assessment
Create a capstone project or final exam that proves mastery. This is your "end goal" made measurable.

#### Step 3: Reverse-Engineer Learning Objectives
For each module/lesson, ask: "What must students know/be able to do BEFORE they can succeed at the final goal?"

### Curriculum Structure Template

```
Course Title: [Specific, outcome-focused]

Course Promise: [One clear sentence of what students achieve]

Duration: [X hours / X weeks]

Target Level: Beginner / Intermediate / Advanced

Prerequisites: [What students should know before starting]

Module 1: [Foundation - gets them from 0 to 25%
Lessons:
  1.1 [Specific skill] - [Duration]
  1.2 [Specific skill] - [Duration]
  Practical Exercise: [Applying what they learned]

Module 2: [Intermediate - gets them from 25% to 50%]
Lessons:
  2.1 [Specific skill] - [Duration]
  2.2 [Specific skill] - [Duration]
  Practical Exercise

Module 3: [Advanced - gets them from 50% to 75%]
Lessons:
  3.1 [Specific skill] - [Duration]
  3.2 [Specific skill] - [Duration]
  Practical Exercise

Module 4: [Integration - gets them from 75% to 100%]
Lessons:
  4.1 [Capstone project guide]
  4.2 [Common mistakes and how to avoid them]
  4.3 [Advanced tips and next steps]

Capstone Project: [Final deliverable]
```

### Lesson Design Template
Each lesson follows this structure:
1. **Hook** (Hook the student — 30 seconds): "In this lesson, you'll learn to..."
2. **Context** (Why it matters): How this connects to the bigger goal
3. **Core Content** (Main teaching — keep under 7 minutes)
4. **Example/Demonstration** (Show, don't just tell — 1-2 minutes)
5. **Action Step** (Student does something immediately — 1 minute)
6. **Summary** (Key takeaway, 30 seconds)
7. **Preview** (Tease next lesson, 10 seconds)

### Content Planning Matrix
| Module | Lessons | Video time | Exercises | Project deliverable |
|--------|---------|------------|-----------|--------------------|
| 1 | 4 | 28 min | 2 | Module 1 deliverable |
| 2 | 5 | 35 min | 3 | Module 2 deliverable |
| 3 | 4 | 28 min | 2 | Module 3 deliverable |
| 4 | 3 | 21 min | 1 | Capstone project |
| **Total** | **16** | **112 min** | **8** | **Final project** |

## Phase 3: Content Production (Weeks 3-5)

### Production Workflow
Use the `video-production-workflow` skill for video-specific guidance.

#### 1. Script Writing
For each lesson, write a script using this template:
```
INTRO: "Hi, I'm [name] from [company]. Welcome to Lesson 1.2 of [course name].
In this lesson, you'll learn [specific skill/habit/concept], 
which is the key to [immediate benefit].

WHY THIS MATTERS:
[Connect to the bigger goal — 1 sentence why this matters]

HOW TO:
[Step 1]
[Step 2]
[Step 3]

EXAMPLE:
[Real-world example or demonstration]

YOUR TURN:
[Action step — student does something immediately]

SUMMARY:
[One-sentence recap]

NEXT TIME:
In the next lesson, we'll cover [tease] which helps you [benefit].
"
```

#### 2. Recording Setup
| Element | Recommendation |
|--------|----------------|
| Microphone | Audio-Technica ATR2100x-USB (~$60) or Blue Yeti (~$130) |
| Camera | 1080p webcam (~$60) or phone with tripod |
| Lighting | Neewer 18-inch ring light (~$30) or 2 softbox lights (~$100) |
| Background | Clean, professional, branded if possible |
| Screen recording | Loom (free) or Camtasia (paid) |
| Recording environment | Quiet room with soft furnishings |

#### 3. Filming Process
1. Set up camera at eye level, good lighting on face
2. Check audio levels (aim for -12 to -6 dB peak)
3. Record in 3-5 minute chunks (easier to edit + re-take)
4. Pause between takes, not mid-sentence
5. Record B-roll of demonstrations/workflow screenshots
6. Record audio separately if screen recording (better audio quality)

#### 4. Editing Workflow
Using free tools (DaVinci Resolve) or paid (Descript, Camtasia):
1. Import all clips
2. Cut out dead air, "ums", long pauses
3. Trim to desired length (most lessons: 5-10 minutes)
4. Add text overlays for key points
5. Insert B-roll for demonstrations
6. Add intro/outro slides
7. Export in 1080p, 30fps, H.264 codec

### Supplementary Materials
For each lesson/module, create:
- **Handouts**: PDF checklists, templates, cheat sheets
- **Workbooks**: Exercises students complete
- **Downloadable assets**: Code files, project templates, resources
- **Resource lists**: Tools, websites, books referenced

## Phase 4: Student Engagement (Week 5-6)

### Engagement Strategy Framework
Choose 3-4 engagement methods from this list:

| Method | Setup Effort | Monthly Effort | Student Value |
|--------|--------------|----------------|----------------|
| Private community (Discord/Slack) | 5 hrs | 3-5 hrs | High |
| Weekly live Q&A | 2 hrs | 1-2 hrs | High |
| Assignment feedback | 2 hrs prep | 5-10 hrs | Very High |
| Peer review | 3 hrs | 2-3 hrs | Medium |
| Progress tracking | 5 hrs | 0-1 hrs | Medium |
| Resource library | 5 hrs | 0-2 hrs | Medium |

### Discussion Prompt Templates
| Lesson Type | Prompt Template |
|-------------|----------------|
| Skill-based | "Show your [deliverable] in the community thread. What was the biggest challenge?" |
| Concept-based | "Where have you seen [concept] applied in your work? Share an example." |
| Project-based | "What's one insight from [topic] you'll apply this week? Comment below." |
| Case study | "[Case study situation]: What would you do differently?" |

### Progress Gamification
```
Progress System:
- Check off each lesson → 100 points
- Complete exercise → 50 points
- Post in community → 25 points
- Peer review → 25 points
- Attend live Q&A → 50 points

Rewards:
- 200 points: Certificate of Completion
- 500 points: Exclusive bonus module
- 1000 points: 1:1 coaching call
```

### Pricing Strategy

#### Price Anchoring
Create 3 tiers:
| Tier | Price | Audience | Conversion |
|------|-------|----------|------------|
| Basic | $97 | Price-sensitive | 5-8% |
| Standard | $197 | Average buyer | 3-5% |
| Premium | $497 | High-value seekers | 1-3% |

Anchor: Most students choose the middle option (Standard tier gets 60% of sales)

#### Pricing Models
| Model | Description | Pros | Cons |
|-------|-------------|------|------|
| One-time payment | Pay once, lifetime access | Simple, high conversion | No recurring revenue |
| Subscription | Monthly recurring | Predictable revenue | Churn risk |
| Payment plan | Split into payments | Lower price point feels | Complex, admin overhead |
| Early bird | Discounted for first N buyers | Creates urgency | May devalue product |
| VIP bundle | Course + coaching + bonus | High ticket, low volume | Requires support capacity |

## Phase 6: Launch Strategy (Week 6-8)

### Pre-Launch Sequence (4 weeks before go-live)
| Week | Action | Goal |
|------|--------|------|
| Week -4 | Create landing page + waitlist | Start collecting emails |
| Week -3 | Content marketing (blog, social) | Build social proof |
| Week -2 | Email nurturing + testimonials | Social proof + interest |
| Week -1 | Scarcity + urgency campaign | Drive last-minute conversions |

### Launch Week Plan
| Day | Action |
|-----|--------|
| Monday | Launch email + social posts |
| Tuesday | Live Q&A session |
| Wednesday | Student success story |
| Thursday | FAQ video + objections answered |
| Friday | Final reminder + last chance |
| Weekend | Community engagement + support |

### Launch Email Sequence
1. **Pre-launch email** (Week -2): "Something big is coming"
2. **Launch announcement** (Monday 9 AM): "Now available — [Course Name]"
3. **How it works** (Tuesday): Course structure + curriculum preview
4. **Success story** (Wednesday): Testimonial from beta students
5. **Objection resolution** (Thursday): FAQ + live Q&A announcement
6. **Last chance** (Friday): Price increase warning + final spots
7. **Post-launch** (Monday): Thank you + next steps

## Phase 7: Post-Launch Optimization (Ongoing)

### Student Success Monitoring
- **Engagement rate**: % completing lessons weekly
- **Drop-off points**: Lessons with high abandon rates
- **Completion rate**: % finishing the course
- **Feedback quality**: Open responses on pain points
- **Support tickets**: Common questions/concerns

### Iteration Plan
| Metric | Threshold | Action |
|--------|-----------|--------|
| Completion <50% | Add more support/simplified lessons |
| Drop-off at lesson X | Rewrite/restructure lesson X |
| Support tickets >10/day | Add FAQ/module improvements |
| NPS < 40 | Survey for pain points, improve content |

## Common Pitfalls
1. **Perfection paralysis** — waiting until every lesson is perfect instead of launching and iterating
2. **No validation** — creating something nobody wants
3. **Overly ambitious scope** — 20-hour courses that never finish vs. 2-hour focused courses
4. **Poor audio quality** — bad audio kills credibility faster than bad video
5. **No engagement plan** — students buy but never engage = high refund rates
6. **Wrong pricing** — too cheap (low perceived value) or too expensive (no buyers)
7. **No community** — lonely students churn quickly
8. **Skipping beta students** — real feedback before public launch is invaluable
9. **No completion path** — students don't finish, can't recommend
