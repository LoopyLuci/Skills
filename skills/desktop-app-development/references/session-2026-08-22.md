### 1. Drag-and-Drop Canvas in PyQt5
```python
class CanvasWidget(QScrollArea):
    def __init__(self):
        self.setAcceptDrops(True)
    
    def dragEnterEvent(self, event):
        if event.mimeData().hasText():
            event.acceptProposedAction()
    
    def dropEvent(self, event):
        # Find drop position based on Y coordinate
        pos = event.pos()
        for i in range(self.layout.count() - 1):
            item = self.layout.itemAt(i)
            if pos.y() < item.widget().geometry().center().y():
                drop_index = i
                break
```

### 3. Properties Panel with Live Editing
```python
class PropertiesPanel(QWidget):
    def load_section(self, section):
        self.clear_form()
        for key, value in section['props'].items():
            if isinstance(value, str):
                edit = QLineEdit(value)
                edit.textChanged.connect(lambda v, k=key: self.on_text_changed(k, v))
                self.form.addRow(f"{key}:", edit)
            elif isinstance(value, (int, float)):
                spin = QDoubleSpinBox()
                spin.setValue(value)
                spin.valueChanged.connect(lambda v, k=key: self.on_number_changed(k, v))
                self.form.addRow(f"{key}:", spin)
```

### 5. Local Model Auto-Detection

class LocalModelDetector:
    @staticmethod
    def check_ollama():
        try:
            r = requests.get("http://localhost:11434/api/tags", timeout=2)
            if r.status_code == 200:
                data = r.json()
                models = [m['name'] for m in data.get('models', [])]
                return True, models
        except:
            pass
        return False, []
    
    @staticmethod
    def detect_all():
        return {
            'ollama': LocalModelDetector.check_ollama(),
            'unsloth': LocalModelDetector.check_unsloth(),

        }

### 6. Native ML Framework (NumPy only)
```python
class Tensor:
    def __init__(self, data, requires_grad=False):
        self.data = np.array(data, dtype=np.float64)
        self.grad = None
        self._backward = lambda: None
    
    def backward(self, grad=None):
        if grad is None:
            grad = np.ones_like(self.data)
        self.grad = grad if self.grad is None else self.grad + grad
        # Topological sort and call _backward on each node
    
    def matmul(self, other):
        out = Tensor(self.data @ other.data)
        out._prev = {self, other}
        def _backward():
            self.backward(out.grad @ other.data.T)
            other.backward(self.data.T @ out.grad)
        out._backward = _backward
        return out
```

## Pitfalls Encountered

1. **setDragEnabled doesn't exist on QPushButton**: Use `mousePressEvent` + `QDrag` + `QMimeData` for drag-and-drop from buttons.

2. **SQLAlchemy model re-registration**: Define models OUTSIDE `create_app()` to avoid "Table already defined" errors when app factory is called multiple times.

3. **Large file writes timeout**: Breaking content into multiple smaller tool calls avoids stream timeouts.

4. **Config class self-reference**: `KEYS_FILE = Config.CONFIG_DIR` fails inside class body — use `CONFIG_DIR` directly.

5. **Flask startup delay**: Poll health endpoint with retry loop rather than using fixed `time.sleep()`.

## Architecture Decisions

1. **Desktop app outside monorepo**: `C:\Users\Server\Desktop\` avoids pnpm workspace conflicts with Electron.

2. **Web app as static HTML**: No build step needed, served by Flask's `send_from_directory`.

3. **ML framework in NumPy only**: Zero external dependencies, fully deterministic, trainable in-app.

4. **Chat as QDockWidget**: Accessible from any tab, can be floating/docked to any side.

5. **Project format as JSON**: Shared between desktop and web editors for seamless switching.
